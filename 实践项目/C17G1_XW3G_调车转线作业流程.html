列车调车转线作业流程详解 故障列车远程接管 · 经由咽喉区的调车转线作业（C17G1 → XW3G）

本阶段属于调车进路建立后的调车运行过程：列车在调车信号允许后低速启动，压入进路内方，经由咽喉区锁闭道岔完成转线，轨道电路占用由起点区段逐步转移至目标区段。当前仿真将咽喉区暂抽象为两个待确认区段（THROAT_1/THROAT_2），仅作拓扑占位，后续由真实进路表和轨道电路编号替换。

二、前置阶段（运行前完成）

前置 1

故障停车与控制权交接（远程接管）

C17G1 占用 ATP 保持制动 控制权：车载/本地 → 地面远程

故障列车迫停于 C17G1。地面操作员申请接管，控制权由车载自动控制或本地控制切换为地面远程控制；列车仍保持停车，制动不立即缓解。该场景对应行业中的远程限制模式（RRM）/ 蠕动模式（CAM）——用于列车因故障迫停区间时，为处理故障争取时间。

前置 2

调车进路办理（请求与联锁检查）

进路：请求中 → 联锁检查 起点占用 ✓ · 目标空闲 ✓ · 道岔可转换 ✓ · 无敌对进路 ✓

操作员请求办理候选调车进路。联锁逐项检查能否建立进路——重点是敌对进路与防护条件：人员防护开关状态纳入联锁进路检查，封锁区域禁止办理任何列车/调车进路；已办理进路应立即关闭相应信号。未确认项在仿真中显示"待确认"，不伪装成真实联锁结果。

前置 3

道岔转换与进路锁闭

道岔：未锁闭 → 转换中 → 锁闭 进路：锁闭保持 车列仍未启动

咽喉区相关道岔转换到进路要求位置，确认到位后进入锁闭状态。此时列车仍停在 C17G1。道岔位置含义：定位为列车沿道岔默认方向运行，反位为列车被导向侧线或另一条连接线。仿真中道岔状态可从"未锁闭 → 转换中 → 锁闭"变化，进路保持锁闭显示为黄色。

前置 4

调车信号开放，车载转入调车模式

信号：关闭 → 允许调车 车载模式：调车（SH） DMI 显示"调车"

始端调车信号开放后，列车获得低压许可，但受调车限速约束（候选 40 km/h）。车载转入调车模式，此时按调车运行规则进行顶棚限速监控，而非完全监控模式下的连续式一次制动曲线。事件流显示"调车信号开放，允许低速运行"。

三、运行阶段（本次重点：低速调车到进入目标区段）

运行 1

车列进入进路内方（低速启动）

牵引：1 级低速 速度：0 → 上升 目标距离：开始递减
  • 车列从 C17G1 起动，速度逐步上升，但不得超过调车限速。
  • C17G1 仍显示占用，直到列车尾部出清起点区段。
  • 目标距离开始递减，车列进入进路内方是"占用通过阶段"的起点。
运行 2

进路锁闭保持（调车进路占用通过）

进路：占用通过（持续锁闭） 道岔不得再转换 · 敌对进路不得办理

运行过程中进路持续保持锁闭，道岔不得再转换、敌对进路不得办理。说明：调车速度低，一般不设接发车进路那样的"接近锁闭"；重点是进路锁闭保持与后续分段解锁。若需体现联锁深度，可把"接近锁闭或进路锁闭保持"列为待确认项。

运行 3

轨道电路占用顺序转移

占用转移：C17G1 → 咽喉区段1 → 咽喉区段2 → XW3G 起点出清变灰

占用按运行方向逐区段前移：C17G1（占用）→ 咽喉区段1（占用）→ 咽喉区段2（占用）→ XW3G（占用）。DMI 动画应表现占用光带逐段移动，而不是列车图标横向跳线。

运行 4

车列通过咽喉区（道岔导向转线）

车列经锁闭道岔尖轨/辙叉通过 被钢轨几何导向目标线路
列车不主动跨线，是道岔提前排好进路后，钢轨把列车导向另一条线。动画应体现车列沿锁闭进路连续移动，而非横向跳转到另一条线。

咽喉区经道岔弯股的进路通常不电码化（无码区），因此本阶段的安全由"进路锁闭 + 地面调车信号 + 低速限速"共同保证，不依赖机车信号的连续信息。这是调车作业在咽喉区安全的行业性原因。

运行 5

进入目标轨道区段 XW3G

当前区段：XW3G（占用） 目标区段：XW3G 进入目标停车控制

车列进入 XW3G，占用光带移入目标区段。此时进路仍保持锁闭，等待列车停稳与作业完成。停车点（计算点）设在防护点前适当距离，两者之间为安全距离。

运行 6

制动停车与进路解锁

制动：常用制动 → 停车 信号：关闭 进路：解锁（分段/一次）· 道岔：解锁
  • 按目标距离与制动距离判断触发常用制动，速度逐步下降至 0。
  • 停稳后远程操作员确认，调车作业完成，进路解锁。
事件流：C17G1 至 XW3G 调车完成 → 信号关闭 → 进路解锁 → 道岔恢复可操作。至此"调车进路建立后的调车运行阶段"结束。
