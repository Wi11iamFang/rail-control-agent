## 3. station.txt 图元语言解读（对标核心）

每个设备是一段 `##XX` 配置，字段即绘图参数：

### 3.1 GD 区段（例：IVG / IIG / IG）

```text
##GD
gd.m_strName="IVG";          # 区段名
gd.GD_Type=GD_QD;            # 轨道区段
gd.p1=P(750,255); gd.p2=P(750,265);     # 轨条1 两端（粗线）
gd.p3=P(1140,255); gd.p4=P(1140,265);   # 轨条2 两端（粗线）
gd.p12=P(750,260); gd.p34=P(1140,260);  # 两轨条中心线两端
gd.pz12=P(870,260); gd.pz34=P(930,260); # 区段文字占位
gd.center=P(945,260);
gd.m_textRect=R(934,239,956,259);       # 区段名文本矩形
```

要点：**一条股道 = 两条平行轨条（p1-p2 / p3-p4）+ 两轨条中间的文字区（pz12-pz34 / m_textRect）**。
占用/空闲/锁闭通过改变轨条颜色表达，文字写在两轨条中间。

### 3.2 DC 道岔（例：9 号、15 号道岔）

```text
##DC
gddc.m_strName="9";
gddc.m_nType=22;                       # 道岔类型（21/22 等）
gddc.p1=P(1430,395); gddc.p2=P(1430,405);   # 方向1 轨条端点
gddc.p3=P(1330,395); gddc.p4=P(1330,405);   # 方向2 轨条端点（直股）
gddc.p5=P(1356,478); gddc.p6=P(1364,482);   # 方向3 轨条端点（侧股）
gddc.p12=P(1430,400); gddc.p34=P(1330,400); gddc.p56=P(1360,480);
gddc.center=P(1400,400);
gddc.pZ12=P(1415,400); gddc.pZ34=P(1365,400); gddc.pZ56=P(1380,440);
gddc.m_textRect=R(1366,414,1373,429);   # 道岔名文本矩形
```

要点：**道岔 = 三方向轨线（直股 p1/p2-p3/p4 + 侧股 p5-p6）+ 中心点 + 名称文本**。
联锁软件中道岔锁闭时以**黄色**点亮相关轨线，定位/反位通过哪条支线接入判断。

### 3.3 XH 信号机（例：D16）

```text
##XH
xhd.m_strName="D16";                   # 信号机名称
xhd.m_nType=31;
xhd.center=P(640,810);                 # 灯位中心
xhd.m_nXHDType=DC_XHJ;                 # 调车信号机
xhd.m_textRect=R(630,774,652,789);     # 名称文本矩形
xhd.safeLamp=XHD_AD;                   # 灯型
xhd.isHigh=FALSE;                      # 矮柱
```

要点：**信号机 = 灯位中心点（center）+ 名称文本（m_textRect）**。调车信号机（DC_XHJ）开放为
**月白色**，关闭为**红色**，灭灯为暗灰。D16 出现在项目 `RouteTopology` 里已是“drawing-label”。

## 4. 当前 YardView 与联锁软件表现的差距对照

| 表现点 | 当前 YardViewRenderer | 联锁软件标准站 | 建议改动 |
|---|---|---|---|
| 轨线 | 单线 `LineWidth 5`（灰色） | 双轨条平行线（p1-p2 / p3-p4） | 每区段两条平行轨条，间距约 8px，粗线 |
| 区段名 | 单行文字于轨线上方 | 文字在两轨条中间（pz12-pz34） | 文字移到双轨条之间 |
| 道岔 | 直股+侧股两分支线 + 圆点枢轴 | 三方向轨线（p1/p3/p5）+ center | 改三方向双轨条画法，锁闭时侧股黄 |
| 信号机 | 圆灯 patch（月白/红/灭）+ 下方文字 | center 灯位 + m_textRect 名称 | 灯位圆形保留，名称位置对齐 |
| 列车 | 蓝色矩形 patch（L46×W18）+ “车列”文字 | 占用光带 + 车次号（如 D2） | 占用区段显示车次号；车列图形优化 |
| 配色 | 深蓝黑底 / 灰轨 / 黄锁闭 / 红占用 | 同类深色底，轨条灰蓝、锁闭黄、占用红 | 统一取联锁软件惯用色值 |
| 进路高亮 | 黄色 route polyline（默认隐藏） | 锁闭进路轨条变黄 | 锁闭时整条进路轨条黄色 |

## 5. 建议改动清单（按优先级）

### P1 轨线改为双轨条平行线（YardViewRenderer.buildStatic 区段部分，131-150 行）
- 每个 section 由一条线改为两条平行线（在显示几何两侧各偏移 ~4px）。
- 颜色状态保留：空闲 `[0.55 0.60 0.66]`、占用红 `[0.90 0.18 0.10]`、锁闭黄 `[1.00 0.94 0.18]`。
- 区段名 `SectionLabels` 位置下移到两轨条中间。

### P2 道岔改三方向符号（switchBranches，225-250 行）
- 直股分支沿用当前 p±40 水平线；侧股分支向 route 下一顶点方向画。
- 锁闭时（`locked-candidate`）侧股轨条变黄加粗（现状已有，保留），枢轴圆点保留。

### P3 信号机灯位 + 名称位置对齐（176-186 行）
- 灯位圆形 patch 保留（月白/红/灭逻辑不动）。
- 名称文字位置微调，使与灯位相对关系接近 m_textRect 布局（名称在灯位下方略偏）。

### P4 列车图像贴近“车列 + 车次号”（188-198 行、262-269 行）
- 保留朝向矩形车身，但改为**圆头车头 + 车身两条腰线**（动车内饰风格），或维持矩形+圆角。
- 车身内/上方显示**车次号 `D2`**（与 RemoteDMIApp 的 TrainNo='D2' 一致）。
- 占用区段的 `SectionLabels` 仍显示区段名；列车到达区段时可在该区段名后追加 `(D2)`，表示光带+车次号。
- “车列”文字可替换为车次号或保留（二选一，建议车次号 `D2`）。

### P5 配色统一（buildStatic / update 全部色值）
- 底 `[0.03 0.04 0.07]`（现状保留）；空闲轨 `[0.55 0.60 0.66]`；
- 锁闭黄 `[1.00 0.94 0.18]`；占用红 `[0.90 0.18 0.10]`；
- 信号开放月白 `[0.95 0.96 1.00]`、关闭红 `[0.92 0.15 0.10]`、灭灯 `[0.20 0.24 0.30]`；
- 车次号文字白色 `[0.92 0.96 1.00]`。

### P6 大屏交互强化（YardViewApp，可选项）
- 信号开放时灯位**闪烁**（已有 Blink 机制在 DMI，可复用思路）。
- 进路锁闭时 route polyline 高亮显示（`RouteLine.Visible='on'` 触发条件与 update 的锁闭判断一致）。

## 6. 实现注意（不破坏现有架构）

- `YardViewRenderer` 是**纯显示端**：只读 `Context.State`，`update` 里已有占用/锁闭/信号/列车逻辑，
  改动集中在 `buildStatic` / `switchBranches` / `moveTrain` 的几何与符号画法。
- 三端共享 `RemoteOperationContext`（同进程 handle，无 TCP/UDP），YardView 大屏和 GroundControl、
  DMI 共用同一个 renderer 实例类 —— 改动 YardViewRenderer 会同时影响地面端左侧站场图，
  这是预期行为（两端画面一致，符合“地面/车载一致”）。
- 设备名仍用 `C21G1 / THROAT_LOCAL_1 / THROAT_LOCAL_2 / D20_APPROACH / XC21 / D16 / W_LOCAL_1/2`，
  不照搬标准站设备名；`station.txt` 只提供画法参考。
- 不引入 TCP/UDP，不新增依赖，不改状态机与 ShuntDriver 业务顺序。
